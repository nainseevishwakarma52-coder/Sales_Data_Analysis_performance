# 📊 Sales Performance & Profitability Analysis (Power BI)

## 📌 Project Overview
An interactive 5-page Power BI dashboard designed to analyze 3,500+ sales orders across major Indian metro cities from 2020 to 2024.

## 🔍 Key Dashboard Highlights
- **Executive Overview**: Net sales distribution across cities, profit margin correlation, and promotion discount efficiency.
- **Top & Bottom 5 Analysis**: Product ranking across Net Sales, Quantity Sold, and Profitability (e.g., Apple iPhone 14, MacBook Air).
- **Dual-Period Comparison**: Side-by-side date slicers enabling direct period-over-period sales and profit evaluations.
- **Transaction Details**: Granular data matrix showing customer orders, discount percentages, and unit profit margins.

## 🛠️ Tools & Technologies Used
- **BI Tool**: Power BI Desktop
- **Calculations**: DAX (Measures & Calculated Columns)
- **Data Transformation**: Power Query
- **Data Source**: Excel Dataset (`/DataSet/Store+Data (1).xlsx`)
